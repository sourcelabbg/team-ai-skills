# Sourcelab team skills

This repo holds our shared skills — short playbooks for how we do specific
jobs. Each one is a `SKILL.md` file under `categories/<category>/skills/`.

**Before starting a task, list `categories/*/skills/*/` and read any `SKILL.md`
whose name matches what you are about to do. If one applies, follow it over
your default approach.**

Categories: `engineering`, `testing`, `review`, `documentation`, `operations`,
`data`.
